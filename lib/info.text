# when deploy web using firebase hosting in Codemagic
we need this file : application_default_credentials.json
added in codemagic.yaml : 
    echo $firebase_service_account | base64 --decode > ~/.config/gcloud/application_default_credentials.json
# 📦 How to get the file:
Go to Google Cloud Console
Navigate to:
IAM & Admin > Service Accounts
Create or select a service account
Click “Keys” → “Add Key” → “Create new key” (JSON)
Save the JSON file
